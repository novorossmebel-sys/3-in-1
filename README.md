# СРЕДА · Калькуляторы (3 в 1)

Три калькулятора СРЕДА, объединённые на одной странице с вкладками и входом по паролю:

| Вкладка | Файл | Что считает |
|---|---|---|
| **Просчёт мебели** | `mebel.html` | Себестоимость изделия, статьи затрат, КП |
| **Фасады** | `fasad.html` | Стоимость фасадов МДФ / шпон, бланк + договор |
| **Распил** | `raspil.html` | Раскрой, кромление, присадка, пазование |

Точка входа — **`index.html`**: сначала спрашивает пароль, затем показывает вкладки. Все три калькулятора работают внутри одной страницы, между вкладками можно переключаться без потери введённых данных.

---

## Пароль

Вход защищён паролем. По умолчанию:

```
01010101
```

**Как сменить пароль:** откройте `index.html` в любом текстовом редакторе, найдите строку

```js
var PASSWORD = "01010101";
```

впишите свой пароль между кавычками и сохраните файл.

> ⚠️ Это простая защита от случайных посетителей (проверка в браузере), а не банковский уровень безопасности. Не размещайте здесь по-настоящему секретных данных.

## Как открыть с любого компьютера

Это обычный статический сайт (4 файла, без сервера и базы данных). Чтобы он был доступен по ссылке с любого компьютера:

1. **GitHub Pages** (бесплатно): в настройках репозитория → *Settings → Pages* → выберите ветку и папку с этими файлами. GitHub выдаст ссылку вида `https://<аккаунт>.github.io/3-in-1/`. Открываете ссылку → вводите пароль → работаете.
2. Либо любой хостинг статических сайтов (Netlify, Vercel, обычный хостинг) — просто загрузите все 4 файла (`index.html`, `mebel.html`, `fasad.html`, `raspil.html`) в одну папку.

Можно также открывать `index.html` локально (двойным щелчком), но онлайн-размещение удобнее для доступа с разных устройств.

## Как сохраняются расчёты

Каждый калькулятор сохраняет расчёты **в памяти браузера** того компьютера, где вы работаете, и умеет **выгружать файл / PDF**:

- **Просчёт мебели** — «Сохранить как…» (список КП в браузере), «Сохранить как… (Excel)», «Скачать копию инструмента (HTML)».
- **Фасады** — 10 последних расчётов в браузере + «Сохранить файл» (отдельный `.html`) + «Печать / PDF» (бланк заказа и договор).
- **Распил** — автосохранение расчётов по названию в браузере + «Печать / сохранить в PDF».

Название документа задаёте в самом калькуляторе — оно попадает в имя выгружаемого файла.

> Список сохранённых расчётов виден только на том компьютере/браузере, где вы их создали. Чтобы перенести расчёт на другой компьютер — выгрузите файл (HTML/PDF/Excel) и откройте его там. Общая база сохранённых расчётов на всех компьютерах сразу потребует облака/сервера — это отдельная доработка.

## Что добавлено в «Просчёт мебели»

По сравнению с исходным калькулятором себестоимости в него внесены **актуальные прайсы**:

- **Полная база ЛДСП / ЛМДФ / МДФ / фанеры из калькулятора «Распил»** — в выпадающем списке материала ЛДСП, помимо декоров Egger, теперь есть Lamarty (Р2 и влагостойкая Р5), фанера меламиновая, панели AGT и 5K, а также каталог АМК-Троя (STANDART, COLOR, CONTEMPO, HARMONY, SILKWAY, MOONLIGHT, FAVORITE, МДФ, ЛМДФ, ЛХДФ). Толщины подставляются по каждому декору из его прайса.
- **Полная база кромки из «Распила»** — к кромке Egger добавлены Lamarty/REHAU (Белый / Фоновые / Древесные), AGT 22×1 и 5K 22×1.
- **Актуальные цены фасадов из калькулятора «Фасады»** — добавлены позиции «Покраска материала заказчика» (фреза / мыло / глянец), а цены обратной стороны (обратка) приведены к прайсу «Фасады»: покраска 4500 ₽/м², шпон 5500 ₽/м².

Исходная логика расчёта, КП и экспорта не менялась.
